今天用 Hexo 把这个博客搭起来了。后来升级到了 **Astro 6**，获得更现代化的开发体验。

## 技术选型

| 方案 | 理由 | 为什么不选 |
|------|------|------------|
| Hexo | Node.js 生态、中文社区活跃 | 主题定制局限 |
| Hugo | 编译快 | Go 模板语法不熟 |
| Astro ✅ | 现代化、零 JS 开销、组件孤岛 | — |
| Next.js | 灵活强大 | 杀鸡用牛刀 |

最终决策：**Astro + GSAP + GitHub Pages**，零成本高性能。

## 设计思路

博客采用科技感深色风格，配合 GSAP 动画实现流畅的页面入场体验。
